# bbport's original documents

These files come from [bbport](https://github.com/deadinside28/bloodborne_pc), the native Bloodborne
port PortGaGotoku is a fork of: its change logs, development log, plans and design notes (some in
Russian). They describe bbport and Bloodborne, not Fist of the North Star: Lost Paradise, and are
kept as they were, for reference and attribution. PortGaGotoku's own documents are one folder up.
