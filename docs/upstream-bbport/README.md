# bbport's original documents

These files come from [bbport](https://github.com/deadinside28/bloodborne_pc), the native Bloodborne
port PortGaGotoku is a fork of. They describe bbport and Bloodborne, not Fist of the North Star: Lost
Paradise, and are kept for reference and attribution. PortGaGotoku's own documents are one folder up.

- `API_BOUNDARY.md`: where the boundary between the game's graphics API and the emulation lies, and
  the plan for moving away from emulation (translated from `EMULATION_REMOVAL_PLAN.ru.md`).
- `PC_MEMORY_MODEL.md`: the PC memory model and the CPU, VRAM and shader cache work of 0.3–0.4
  (translated from `CHANGES_2026-10-06.md` and `CHANGES_0.4.md`).
- `HOW_THE_PORT_IS_BUILT.md`: the structure of the port (translated from a section of `ROADMAP.md`).
- `parallel_gpu.md`: the design of the parallel GPU command processing PortGaGotoku uses (as written).

bbport's other documents (change logs, the development log, the roadmap, the upscaler, TAA and motion
vector notes, `history/`) were removed: they are about Bloodborne and its upscaler. They are in this
repository's history up to commit 13429f2 (`docs/upstream-bbport/`) and in bbport's own repository
(last bbport commit here: daa7165, 0.4).
